# NanoGPT 도구 (st-nanogpt)

[English](README.md)

[NanoGPT](https://nano-gpt.com) 사용자를 위한 SillyTavern 확장입니다. 잔액과 구독 사용량을 한눈에 보고, 이미지 생성 설정을 거치지 않고 바로 이미지를 만들 수 있습니다. 휴대폰 화면을 기준으로 만들었습니다.

SillyTavern에 이미 있는 NanoGPT 기능만 사용합니다. API 키는 SillyTavern secrets에 그대로 있고, 확장은 키를 읽지 않습니다.

## 기능

- **사용량 배지**: 상단바 아래 또는 입력창 위(왼쪽·가운데·오른쪽 선택)에 사용량을 보여 주는 작은 버튼. 잔액·이번 주 토큰·오늘 토큰·오늘 이미지 중 원하는 것을 골라 넣고, 구독 사용량은 비율·쓴 양/한도·남은 양 중 하나로 보여 줍니다(예: `$12.35 · 주 42%`, `주 45.7M/60M · 이미지 73/100`). 누르면 패널이 열립니다.
- **사용량 탭**: USD/NANO 잔액, 구독 상태와 만료일, 주간 토큰·일간 토큰·일일 이미지 진행률과 초기화 시각.
- **새로고침**: 두 가지를 따로 켭니다.
  - **사용 후 새로고침**: NanoGPT 응답을 받거나 이미지를 만들면 바로 조회합니다. 연달아 쓰면 15초에 한 번만.
  - **정기 새로고침**: 사용하지 않아도 1분~1시간마다 조회합니다. 다른 기기나 앱에서 쓴 사용량을 따라잡을 때 쓰세요. ST가 백그라운드에 있으면 쉽니다.
- **이미지 탭**: 모델·크기를 고르고 프롬프트를 쓰거나, 프롬프트 제목 옆 **자동생성**을 펼쳐 채팅 모델이 메시지를 보고 프롬프트를 쓰게 한 뒤 생성. 결과는 채팅에 보내기, 저장, 프롬프트 재사용이 가능하고 이번 세션에 만든 이미지는 썸네일로 남습니다. 바꾼 값은 모두 저장되고, **고급 → 이미지 생성 확장 설정 가져오기**로 ST 이미지 생성 확장의 크기·스텝·CFG·공통 프롬프트 접두사·부정 공통 프롬프트 접두사(소스가 NanoGPT면 모델까지)를 가져옵니다. 그 확장이 이미 NanoGPT를 쓰고 있으면 처음 한 번은 자동으로 가져옵니다. 크기 목록은 고른 모델이 받는 크기만 보여 주고, 모델을 바꾸면 그 모델의 권장 스텝·CFG로 맞춥니다(**고급**에 권장값과 범위 표시, **권장값으로** 버튼). 이 정보는 NanoGPT의 공개 모델 목록에서 키 없이 받아 옵니다. **고급 → 스타일**에서 공통 프롬프트 접두사·부정 접두사를 이름 붙여 저장하고 골라 쓸 수 있으며, ST 이미지 생성 확장의 스타일 목록과 같은 것이라 어느 쪽에서 고쳐도 양쪽에 보입니다.
- **프롬프트 자동생성**: 그릴 메시지를 고릅니다(기본은 최신, 드롭다운에는 최근 5개). 채팅 모델에는 그 메시지와 앞 메시지 몇 개, 캐릭터·페르소나 설명만 보내서 평소 답변보다 토큰이 훨씬 적게 듭니다. 연결 관리자 프로필(예: 가볍고 비용이 적게 드는 모델)을 따로 골라 보낼 수 있고, 채팅 연결은 그대로입니다. 더 이전 메시지는 그 메시지의 … 메뉴에서 ⚡를 누르면 됩니다. 드롭다운의 **캐릭터 설정만**을 고르면 채팅 내용 없이 캐릭터 설명만으로 모습을 그리는 프롬프트를 씁니다. 한 번 쓴 프롬프트는 기록해 두어(`user/files/st-nanogpt-prompts.json`, 채팅 파일은 건드리지 않음), 같은 메시지로 다시 들어오면 새로 쓰지 않고 불러옵니다(메시지를 고치거나 스와이프하면 다시 씀). 새로 쓰고 싶으면 **새로 작성**을 누르세요. 프롬프트 칸은 패널을 열 때마다 빈칸이고, ⚡로 들어오거나 드롭다운에서 메시지를 골랐을 때만 그 메시지의 프롬프트가 채워집니다. 불러오거나 쓴 프롬프트를 고친 뒤 생성하면, 고친 버전이 그 메시지의 기록이 됩니다.
- **갤러리 탭**: 서버 갤러리의 이미지를 폴더(캐릭터)별로 모아 봅니다. 눌러서 크게 보고, 좌우로 넘기고, 채팅에 보내거나, 기기에 저장하거나, 삭제할 수 있습니다(삭제는 확인 후). **생성 정보**(모델·프롬프트·크기·스텝·CFG·부정 프롬프트)를 보고 **그대로 다시 생성**하거나 **설정 불러오기**로 고쳐서 다시 만들 수 있습니다. 생성 정보는 이 기능 이후 이 확장으로 만든 이미지만 있습니다. ST 이미지 생성 확장이 만든 이미지도 함께 보입니다. 위쪽 전환으로 **이 채팅**에서 만든 것만 보거나 **폴더 전체**(캐릭터 전체)를 볼 수 있습니다. 이미지가 많아도 가볍게 30장씩 보여 주고 **더 보기**로 더 불러오며, **선택**을 누르면 여러 장을 골라 한 번에 지울 수 있습니다.
- **마법봉 메뉴**: 잔액이 붙은 **NanoGPT** 항목.
- **슬래시 명령어**
  - `/nanogpt [usage|image|gallery]` 패널 열기
  - `/nanousage [quiet=true] [format=text|json]` 사용량 조회 결과 반환
  - `/nanoimage [model=…] [size=832x1216] [negative=…] [send=false] 프롬프트` 이미지를 만들어 채팅에 추가하고 이미지 경로 반환

## 필요 조건

- **API 연결 → Chat Completion → NanoGPT**에 NanoGPT API 키가 저장돼 있어야 합니다.
- `/api/nanogpt/credits`가 있는 SillyTavern 버전(NanoGPT 키 옆에 "View credits" 버튼이 있는 버전).

## 설치

SillyTavern에서 **확장 → 확장 설치**를 누르고 이 저장소 주소를 붙여 넣습니다.

## 채팅에 보내기 방식

메시지에서 만든 그림을 **채팅에 보내기** 할 때 어떻게 붙일지 설정(이미지 → 채팅에 보내기)에서 고릅니다.

| 방식 | 그 메시지 자리에 보이는지 | AI에 영향 | 확장이 있어야 보이는지 |
|---|---|---|---|
| **메시지 아래에 보여 주기** (기본) | ✅ | 없음 | ✅ (확장을 끄면 안 보임) |
| **메시지에 첨부** | ✅ | 이미지를 읽는 모델은 그림을 봄 | ❌ (확장 없어도 보임) |
| **맨 아래 숨김 메시지** | ❌ (맨 끝) | 없음 \* | ❌ (확장 없어도 보임) |

- \* "맨 아래 이미지 메시지를 AI에게 숨기기"가 켜져 있을 때(기본)만입니다. 끄면 일반 메시지가 되어 프롬프트 글이 AI에게 가고, 이미지를 읽는 모델은 그림도 봅니다.
- 어느 방식이든 그림은 그것을 만든 스와이프에서만 보입니다.
- 같은 메시지에 여러 장을 붙이면 바꾸지 않고 추가됩니다. **메시지 아래에 보여 주기**는 한 장씩 크게 보이고 ‹ 2 / 5 › 버튼이나 좌우로 밀어서 넘깁니다(방금 붙인 그림이 먼저). ✕는 지금 보이는 그림만 뺍니다.
- 직접 쓴 프롬프트로 만든 그림이나, 그 사이 메시지가 고쳐졌거나 스와이프된 경우에는 설정과 상관없이 맨 아래 숨김 메시지로 갑니다.
- 갤러리에서 보낼 때도 같습니다(그림을 만든 메시지가 기록돼 있을 때).

### 채팅에서 이미지 지우기

"채팅에서 빼기"와 "이미지 파일까지 지우기"는 따로입니다.

| 방식 | 채팅에서 빼기 | 파일까지 지우기 |
|---|---|---|
| **메시지 아래에 보여 주기** | 그림 오른쪽 위 **✕** (여러 장이면 지금 보이는 장만) | 갤러리 탭에서 **[삭제]** — 그 그림을 보여 주던 메시지에서도 함께 빠짐 |
| **메시지에 첨부** | 그림을 탭(PC는 마우스 올리기) → **🗑** → "하나 삭제" 또는 "모두 삭제" | 같은 확인 창의 **"서버에서 파일도 삭제"** 체크(ST 기본값은 켜짐). 남기려면 끄기 |
| **맨 아래 숨김 메시지** | 메시지를 평소처럼 지우기(… 메뉴나 편집 → 🗑), 또는 그림의 **🗑** | 갤러리 탭에서 **[삭제]** |

- ✕로 빼기만 하면 이미지 파일은 갤러리에 남습니다.
- ST의 🗑로 파일까지 지우면 이 확장의 생성 정보 기록은 남지만 쓰이지 않을 뿐 문제는 없습니다. 같은 그림을 "메시지 아래에 보여 주기"로도 붙여 뒀다면 그쪽은 깨진 그림이 되니 ✕로 빼 주세요.


## 참고

- 이미지 생성 정보와 써 둔 프롬프트를 몇 개까지 기록할지 설정의 **기록**에서 정할 수 있습니다(기록 안 함 ~ 5,000개). 줄이면 오래된 것부터 지우기 전에 확인합니다.

- 설정은 SillyTavern의 `settings.json`이 아니라 별도 파일 `data/<사용자>/user/files/st-nanogpt-settings.json`에 저장됩니다. 확장을 삭제하면 이 파일과 이미지 생성 정보(`st-nanogpt-images.json`), 써 둔 프롬프트(`st-nanogpt-prompts.json`), 메시지 아래 그림(`st-nanogpt-inserts.json`) 파일도 같이 지워집니다. 갤러리 이미지 자체는 채팅에서 쓰고 있을 수 있어 지우지 않습니다.

- **중지**는 SillyTavern에서 기다리는 것만 멈춥니다. NanoGPT 쪽에서는 이미지가 계속 만들어져 요금이 나갈 수 있습니다.
- 만든 이미지는 기본적으로 바로 서버 갤러리(`data/<사용자>/user/images/<캐릭터 이름>/`)에 저장됩니다. 설정에서 끄면 채팅에 보낼 때만 저장합니다.
- **채팅에 보내기** 방식은 위 [채팅에 보내기 방식](#채팅에-보내기-방식)을 보세요.
- 맨 아래로 보낸 이미지는 기본적으로 숨김 메시지라서 프롬프트가 모델에게 가지 않습니다. **확장 → NanoGPT 도구**에서 바꿀 수 있습니다.
- 모델에 따라 스텝·CFG·부정 프롬프트를 무시하기도 합니다.
