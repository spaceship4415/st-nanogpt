# NanoGPT 도구 (st-nanogpt)

[English](README.md)

[NanoGPT](https://nano-gpt.com) 사용자를 위한 SillyTavern 확장입니다. 잔액과 구독 사용량을 한눈에 보고, 이미지 생성 설정을 거치지 않고 바로 이미지를 만들 수 있습니다. 휴대폰 화면을 기준으로 만들었습니다.

SillyTavern에 이미 있는 NanoGPT 기능만 사용합니다. API 키는 SillyTavern secrets에 그대로 있고, 확장은 키를 읽지 않습니다.

## 기능

- **사용량 배지**: 상단바 아래 또는 입력창 위(왼쪽·가운데·오른쪽 선택)에 잔액과 이번 주 구독 사용량을 보여 주는 작은 버튼(예: `$12.35 · 주 42%`). 누르면 패널이 열립니다.
- **사용량 탭**: USD/NANO 잔액, 구독 상태와 만료일, 주간 토큰·일간 토큰·일일 이미지 진행률과 초기화 시각.
- **새로고침**: 두 가지를 따로 켭니다.
  - **사용 후 새로고침**: NanoGPT 응답을 받거나 이미지를 만들면 바로 조회합니다. 연달아 쓰면 15초에 한 번만.
  - **정기 새로고침**: 사용하지 않아도 1분~1시간마다 조회합니다. 다른 기기나 앱에서 쓴 사용량을 따라잡을 때 쓰세요. ST가 백그라운드에 있으면 쉽니다.
- **이미지 탭**: 모델·크기를 고르고 프롬프트를 쓰거나, 프롬프트 제목 옆 **자동생성**을 펼쳐 채팅 모델이 메시지를 보고 프롬프트를 쓰게 한 뒤 생성. 결과는 채팅에 보내기, 저장, 프롬프트 재사용이 가능하고 이번 세션에 만든 이미지는 썸네일로 남습니다. 바꾼 값은 모두 저장되고, **고급 → 이미지 생성 확장 설정 가져오기**로 ST 이미지 생성 확장의 크기·스텝·CFG·앞에 붙일 프롬프트·네거티브(소스가 NanoGPT면 모델까지)를 가져옵니다. 그 확장이 이미 NanoGPT를 쓰고 있으면 처음 한 번은 자동으로 가져옵니다.
- **프롬프트 자동생성**: 그릴 메시지를 고릅니다(기본은 최신, 드롭다운에는 최근 5개). 채팅 모델에는 그 메시지와 앞 메시지 몇 개, 캐릭터·페르소나 설명만 보내서 평소 답변보다 토큰이 훨씬 적게 듭니다. 연결 관리자 프로필(예: 가볍고 비용이 적게 드는 모델)을 따로 골라 보낼 수 있고, 채팅 연결은 그대로입니다. 더 이전 메시지는 그 메시지의 … 메뉴에서 ⚡를 누르면 됩니다. 드롭다운의 **캐릭터 설정만**을 고르면 채팅 내용 없이 캐릭터 설명만으로 모습을 그리는 프롬프트를 씁니다. 한 번 쓴 프롬프트는 기록해 두어(`user/files/st-nanogpt-prompts.json`, 채팅 파일은 건드리지 않음), 같은 메시지로 다시 들어오면 새로 쓰지 않고 불러옵니다(메시지를 고치거나 스와이프하면 다시 씀). 새로 쓰고 싶으면 **새로 작성**을 누르세요. 프롬프트 칸은 패널을 열 때마다 빈칸이고, ⚡로 들어오거나 드롭다운에서 메시지를 골랐을 때만 그 메시지의 프롬프트가 채워집니다. 불러오거나 쓴 프롬프트를 고친 뒤 생성하면, 고친 버전이 그 메시지의 기록이 됩니다.
- **갤러리 탭**: 서버 갤러리의 이미지를 폴더(캐릭터)별로 모아 봅니다. 눌러서 크게 보고, 좌우로 넘기고, 채팅에 보내거나, 기기에 저장하거나, 삭제할 수 있습니다(삭제는 확인 후). **생성 정보**(모델·프롬프트·크기·스텝·CFG·네거티브)를 보고 **그대로 다시 생성**하거나 **설정 불러오기**로 고쳐서 다시 만들 수 있습니다. 생성 정보는 이 기능 이후 이 확장으로 만든 이미지만 있습니다. ST 이미지 생성 확장이 만든 이미지도 함께 보입니다. 위쪽 전환으로 **이 채팅**에서 만든 것만 보거나 **폴더 전체**(캐릭터 전체)를 볼 수 있습니다.
- **마법봉 메뉴**: 잔액이 붙은 **NanoGPT** 항목.
- **슬래시 명령어**
  - `/nanogpt [usage|image|gallery]` 패널 열기
  - `/nanousage [quiet=true] [format=text|json]` 사용량 조회 결과 반환
  - `/nanoimage [model=…] [size=832x1216] [negative=…] [send=false] 프롬프트` 이미지를 만들어 채팅에 추가하고 이미지 경로 반환

## 필요 조건

- **API 연결 → Chat Completion → NanoGPT**에 NanoGPT API 키가 저장돼 있어야 합니다.
- `/api/nanogpt/credits`가 있는 SillyTavern 버전(NanoGPT 키 옆에 "View credits" 버튼이 있는 버전).

## 설치

SillyTavern에서 **확장 → 확장 설치**를 누르고 이 저장소 주소를 붙여 넣습니다.

## 참고

- 이미지 생성 정보와 써 둔 프롬프트를 몇 개까지 기록할지 설정의 **기록**에서 정할 수 있습니다(기록 안 함 ~ 5,000개). 줄이면 오래된 것부터 지우기 전에 확인합니다.

- 설정은 SillyTavern의 `settings.json`이 아니라 별도 파일 `data/<사용자>/user/files/st-nanogpt-settings.json`에 저장됩니다. 확장을 삭제하면 이 파일과 이미지 생성 정보(`st-nanogpt-images.json`), 써 둔 프롬프트(`st-nanogpt-prompts.json`) 파일도 같이 지워집니다. 갤러리 이미지 자체는 채팅에서 쓰고 있을 수 있어 지우지 않습니다.

- **중지**는 SillyTavern에서 기다리는 것만 멈춥니다. NanoGPT 쪽에서는 이미지가 계속 만들어져 요금이 나갈 수 있습니다.
- 만든 이미지는 기본적으로 바로 서버 갤러리(`data/<사용자>/user/images/<캐릭터 이름>/`)에 저장됩니다. 설정에서 끄면 채팅에 보낼 때만 저장합니다.
- 채팅에 보낸 이미지는 기본적으로 숨김 메시지라서 프롬프트가 모델에게 가지 않습니다. **확장 → NanoGPT 도구**에서 바꿀 수 있습니다.
- 모델에 따라 스텝·CFG·네거티브 프롬프트를 무시하기도 합니다.
